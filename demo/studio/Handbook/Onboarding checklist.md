# Onboarding checklist

## Before your first day

- [ ] Laptop set up and encrypted
- [ ] Accounts for the [[Tools]] we use
- [ ] A desk by the window, if you want one

## First week

- [ ] Read [[How we work]] and the [[Writing style]] guide
- [ ] Sit in on a client call
- [ ] Lunch with everyone (the studio pays)

## Second week

- [ ] Ship one small change to a live project
- [ ] Book your first holiday; see [[Holidays and leave]]
