# Tools

| What | Tool | Why |
| --- | --- | --- |
| Notes and this handbook | Commonplace | Plain Markdown, editable together, publishes as this site |
| Design | A shared design file per project | One source of truth for each client |
| Code | Git, with a pull request for every change | Someone else always reads it |
| Chat | One channel per project | Decisions get copied into the project's page |
| Time | A weekly timesheet | Keeps [[How we work#Estimate\|estimates]] honest |

> [!tip]
> If a decision only lives in chat, it didn't happen. Write it on the project page.
