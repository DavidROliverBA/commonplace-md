# Keyboard shortcuts

On Windows and Linux, use Ctrl where it says ⌘.

## Anywhere

| Keys | What it does |
| --- | --- |
| `⌘K` or `⌘P` | Every command, in one list |
| `⌘O` | Find a note by name, or make it |
| `⌥N` | New note |
| `⌘⇧F` | Search |
| `⌘\` | Show or hide the file panel |
| `⌘J` | The AI side panel |
| `Esc` | Close a dialog or menu, or leave focus mode |

## While writing

| Keys | What it does |
| --- | --- |
| `/` at the start of a line | Insert a block: heading, list, to-do, table, callout and more |
| `[[` | Link to a note, with suggestions |
| `#` | Add a tag, with suggestions |
| `@` and an assistant's name | Ask that AI assistant, under this line |
| `⌘⇧H` | Colour or highlight the selected text |
| `⌘`-click a link | Follow it |
| `⌘Z` / `⌘⇧Z` | Undo and redo your own changes |
| `⌘F` | Find in this note |
| `Tab` / `⇧Tab` | Indent and outdent a list item; next and previous cell in a table |
| `Enter` in a table | The cell below |
| Paste or drop a picture | Upload it and show it in the note |

## In lists and menus

| Keys | What it does |
| --- | --- |
| `↑` `↓` | Move through the results |
| `Enter` | Choose |
| `Esc` | Close |

> [!note] In the standalone file
> `⌘O` (and `⌘P`) open a note by name, `⌘⇧F` searches, `⌘\` shows or hides the file panel, and `⌘S` saves to the folder straight away. `/`, `[[`, `#` and the editor's keys work as in the app. There's no command list, `⌥N` or AI.
